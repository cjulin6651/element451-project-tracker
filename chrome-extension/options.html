Google OAuth setup

This version connects directly to Project Tracker. The dashboard does not need to be open.

Extension ID:

  1. In the same Google Cloud project used by Project Tracker, enable the Google Apps Script API.
  2. Create an OAuth client of type Chrome Extension using the Extension ID above.
  3. Copy the generated client ID.
  4. Open manifest.json in a text editor and replace the OAuth client_id value with that client ID.
  5. Return to chrome://extensions and click Reload on Project Tracker.
  6. Come back here and click Test connection. The first test will ask you to authorize Google once.

After this one-time setup, normal extension use does not depend on an open Project Tracker tab.
